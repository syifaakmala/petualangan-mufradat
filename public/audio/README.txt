Folder audio untuk rekaman final.

Versi awal website menggunakan Web Speech API pada browser (suara Arab dan Indonesia bergantung pada perangkat/browser). Untuk hasil pembelajaran yang benar-benar jelas, ganti fallback tersebut dengan rekaman penutur/guru bahasa Arab yang fasih.

Pola nama file yang disarankan:
- vocabulary/<topic-id>/<item-id>.mp3
- feedback/hebat.mp3
- feedback/bagus.mp3
- feedback/coba-lagi.mp3

Sebelum dipakai untuk penilaian/tugas akhir, periksa kembali setiap kosakata, harakat, konteks, dan rekaman pengucapannya dengan pengajar bahasa Arab.
